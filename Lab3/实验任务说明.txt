26年秋季机器学习专题训练 第三次实验：基于朴素贝叶斯的智能助手意图识别

实验目标

1. 理解词袋表示、类别先验和条件独立假设。
2. 手写多项式朴素贝叶斯，实现完整150类意图分类。
3. 理解加法平滑、对数计算以及批量分类得分。
4. 通过控制变量对照和错误分析，理解预处理与模型假设的作用。

一、必做代码：naive_bayes.py中的5处TODO

TODO 1：类别先验
统计各类别包含的训练文档数，计算对数先验概率。
不可将先验写死为1/150，小例中的类别并不均衡。

TODO 2：每类词频
累加同一类所有训练文档中的词频，构造[类别数,词表大小]矩阵。
区别“文档数”“词语总次数”和“包含某词的文档数”。

TODO 3：平滑后的条件概率
使用alpha进行加法平滑，按类别归一化后取对数。
加法平滑中的alpha不是前两次实验的L2正则化系数。
注意平滑分母、求和维度和输出形状。

TODO 4：批量分类得分
计算每个样本在每个类别下的对数联合得分，包含类别先验。
返回[批次样本数,类别数]的NumPy数组。不要把未归一化得分当概率。

TODO 5：预测类别
逐样本选择最高得分类别，通过classes_将列索引映射回真实标签。
不要假定标签一定从0开始连续编号。

允许使用NumPy、SciPy和已提供的特征框架。
不得直接调用sklearn.naive_bayes中的分类器替代必做或附加题的核心算法。
其他代码原则上保留，若确需修改，应在报告中说明原因。

二、手算核对

给定三个文档的词频矩阵和标签：

    X = [[2, 1, 0],
         [0, 1, 1],
         [0, 0, 2]]
    y = [2, 2, 8]
    alpha = 1

这里类别记为2和8，词表只有三个词a、b、c。
新文档为[1,0,1]。

请手算并与check_examples.py核对：
1. 各类文档数量、先验概率；
2. 每类词频统计；
3. 平滑后的条件概率；
4. 新文档在两个类别下的对数得分及预测标签。

三、必做对照实验

对照1：固定单词特征、保留停用词，分别令alpha为0.1、0.5、1。
对照2：固定alpha=1和单词特征，比较保留/删除停用词。
保持数据划分、分词规则和其余参数一致，复用重复的基线结果。

记录配置、验证准确率和Macro-F1。根据验证集确定最终配置后，
显式使用--final-test评价测试集，报告最终测试指标。
不要求某一种预处理一定提高准确率，也不按“必须超过某个分数”判断正确性。

四、错误分析

查看validation_errors.csv和validation_confusion_pairs.csv：
1. 找出至少一组容易混淆的意图，说明它们的含义有何区别；
2. 选3条错误句子，解释可能误判的原因；
3. 讨论词袋模型忽略词序、近义表达或词表外词带来的限制。
